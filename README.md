# NESTORY - MVP site web

Site web Next.js pour une marketplace de location longue durée entre propriétaires et locataires.

## Lancer le site en local

1. Installer Node.js : https://nodejs.org
2. Ouvrir un terminal dans ce dossier
3. Lancer :

```bash
npm install
npm run dev
```

4. Ouvrir : http://localhost:3000

## Mettre en ligne gratuitement

Le plus simple :

1. Créer un compte GitHub
2. Créer un nouveau repository
3. Envoyer ce dossier sur GitHub
4. Créer un compte Vercel
5. Importer le repository GitHub dans Vercel
6. Cliquer sur Deploy
